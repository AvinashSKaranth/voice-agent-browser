ASR Streaming Bench

Four speech models transcribing the same 29-second clip: two clear speakers, then two deliberately unclear ones. Each was timed as a one-shot transcription and as a live stream fed one word at a time, natively on this laptop and inside Chrome.

Phonon-2 builds

Which Phonon-2 quant can run in a browser

Every quantization listed under FermionResearch/Phonon-2 on Hugging Face. Both browser-capable builds keep Fermion's weights exact, so they transcribe exactly like the native engine. The difference is speed and download size.

Neither browser build keeps up with live speech on the CPU. The engine is already doing about 19 GFLOPS on one WASM thread; going faster needs threads, which need COOP/COEP headers that GitHub Pages can't send (a coi-serviceworker shim can add them). For comparison, Fermion's native CPU engine needs 274 ms on all 20 threads of the i9, using int8 dot-product instructions that WASM lacks.
